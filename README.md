# روستر فالكون المقترح 2027

مقترح مستقل لروستر فالكون في أوفرواتش لموسم 2027. ما يمثل فالكون ولا بليزارد.

الموقع: https://falcons-roster.github.io/

## كيف أعدّل الموقع؟

كل المحتوى (الأرقام والنصوص بالعربي والإنجليزي) موجود في ملف واحد: **`data.js`**.

1. افتح ملف `data.js` هنا في GitHub.
2. اضغط أيقونة القلم (Edit) فوق الملف.
3. عدّل اللي تبيه. استخدم Ctrl+F عشان تلقى المكان بسرعة:
   - `const DATA` للأرقام واللاعبين والبطولات
   - `ar: {` للنصوص العربية
   - `en: {` للنصوص الإنجليزية
   - `HERO_AR` لأسماء الهيروات بالعربي
   - `asOf` لتاريخ آخر تحديث
4. اضغط **Commit changes**. الموقع يتحدث خلال دقيقة تقريبا.

انتبه إن كل نص يكون بين علامتي تنصيص `" "`، ولا تحذف الفواصل في آخر الأسطر.
لو صار خطأ والموقع ما فتح، ارجع لصفحة History في GitHub وتقدر ترجع للنسخة اللي قبل.

## الملفات

| الملف | وش فيه |
|---|---|
| `data.js` | الأرقام والنصوص، هذا اللي تعدّله غالبا |
| `app.js` | طريقة عرض الصفحة والتفاعل |
| `style.css` | الألوان والتصميم والحركة |
| `img/` | صور اللاعبين وشعارات الفرق |
| `og.png` | الصورة اللي تطلع لما ينرسل الرابط |

ملاحظة: بعد أي تعديل كبير، غيّر الرقم اللي بعد `?v=` في `index.html` (ثلاث أماكن) عشان الزوار يشوفون النسخة الجديدة مباشرة.
